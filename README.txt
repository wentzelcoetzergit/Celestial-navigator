CELESTIAL NAVIGATOR V1 — INSTALLABLE WEB APP

1. Unzip the package.
2. Create a PUBLIC GitHub repository and upload the five files in this folder to its root.
3. In repository Settings > Pages, select Deploy from a branch, main, /(root), Save.
4. Wait for the HTTPS GitHub Pages URL, then open it in Safari on iPhone.
5. Safari Share > Add to Home Screen > Add. Android Chrome: menu > Add to Home screen or Install app.
6. Visit online once before relying on offline use.

The HTML file must be hosted over HTTPS for installation and offline caching. Opening it in the ChatGPT file preview is not the same as opening the installed app.

WARNING: Educational calculations. Sun and Moon corrections are approximate; verify against Nautical Almanac before actual navigation.
